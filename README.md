# Моды для коопа в Cyberpunk 2077

Отсюда установщик «Моды для коопа.exe» берёт обновления. Руками здесь ничего качать не нужно:
запусти установщик и нажми кнопку, он сам скачает актуальную версию.

- `versiya.txt`: номер актуальной версии и ссылка на набор.
- `mody-N.zip`: набор, пути от корня игры. Внутри Cyber Engine Tweaks (MIT, https://github.com/maximegmd/CyberEngineTweaks) и наши моды.
